🚀 NASIL ÇALIŞTIRILIR?
═══════════════════════════════════════════════════════════════════════════

1. KURULUM
   --------
   pip install -r requirements.txt
   pip install -r requirements_app.txt

2. ANA PROGRAMI ÇALIŞTIR (ML Pipeline)
   ------------------------------------
   python main.py
   
   Bu komut şunları yapar:
   ✓ Veriyi yükler ve temizler
   ✓ 3 modeli eğitir ve optimize eder
   ✓ Performans metriklerini hesaplar
   ✓ 11 görselleştirme oluşturur
   ✓ Word raporu hazırlar
   ✓ En iyi modeli kaydeder
   
   Çalışma süresi: ~5-10 saniye

3. WEB UYGULAMASINI BAŞLAT
   ------------------------
   streamlit run app.py
   
   Tarayıcıda otomatik açılır: http://localhost:8501
   
   Web uygulaması özellikleri:
   📊 İnteraktif veri analizi grafikleri
   🤖 Model performans karşılaştırması
   🔮 Gerçek zamanlı kalp hastalığı riski tahmini
   📈 Confusion matrix ve ROC curve görselleri

🔍 ÖNEMLİ BULGULAR
═══════════════════════════════════════════════════════════════════════════

📌 En Önemli Risk Faktörleri (önem sırasına göre):
   1. Göğüs ağrısı tipi (cp)
   2. Maksimum kalp atış hızı (thalach)
   3. ST depresyonu (oldpeak)
   4. Ana damar sayısı (ca)
   5. Cinsiyet (erkeklerde 2.2x daha fazla risk)
   6. Yaş (artan yaş ile risk artıyor)

📊 Veri Seti İstatistikleri:
   • Toplam hasta: 303 kişi
   • Hasta/sağlıklı oranı: %54.5 / %45.5 (dengeli)
   • Yaş aralığı: 29-77 yaş
   • Ortalama yaş: 54.4 ± 9.1 yıl
   • Erkek oranı: %68.3

🎯 Model Başarısı:
   ✓ %60 genel doğruluk
   ✓ %81 hasta tespiti (yüksek recall - önemli!)
   ✓ GridSearchCV ile optimize edildi
   ✓ 3-fold cross validation yapıldı
